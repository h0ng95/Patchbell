# Patchbell 데스크톱

Windows와 macOS에서 프로그램, 에디터, SDK, 런타임과 npm 패키지의 설치 버전을 등록하고 관련 공개 보안 공지를 확인하는 Flutter 앱입니다.

## 실행

Flutter를 설치한 뒤 이 폴더에서 실행합니다.

- Mac에서 실행하려면 Xcode가 필요합니다. 명령은 **flutter run -d macos**입니다.
- Windows에서 실행하려면 Visual Studio의 Desktop development with C++ 워크로드가 필요합니다. 명령은 **flutter run -d windows**입니다.

Mac에서 실행하면 메뉴 막대 오른쪽에 종 모양 아이콘이 나타납니다. 빨간 숫자는 일치하는 공지가 있는 등록 항목 수입니다. 메뉴에서 항목을 선택해 공지를 볼 수 있고 **등록하기**를 누르면 등록 창이 열립니다.

Mac에서는 창을 닫아도 메뉴 막대에서 실행되며, **Patchbell 종료**를 선택하면 종료됩니다. **데스크톱 알림**에서 알림을 켤 수 있습니다.

Windows에서는 작업 표시줄과 시계 옆 트레이의 Patchbell 아이콘에 공지가 있는 등록 항목 수가 빨간 배지로 표시됩니다. 창을 닫아도 트레이에서 실행됩니다. 트레이 아이콘을 클릭하면 창이 열리고, 오른쪽 클릭 메뉴의 **Patchbell 종료**로 앱을 끝낼 수 있습니다. 트레이 아이콘이 접혀 있으면 작업 표시줄의 **^**에서 찾아 시계 옆으로 끌어 놓으면 계속 표시됩니다.

오른쪽 위 **설정**에서 앱 언어를 선택하고, 해·달 버튼으로 라이트 모드와 다크 모드를 전환합니다. 처음에는 시스템 화면 모드를 따르며, 버튼으로 선택한 모드는 이 기기에 저장됩니다.

## 버전과 공지 연결

- **설치 버전 찾기**에서 Flutter, Dart, Node.js, Python, VS Code를 찾아 원하는 버전만 골라 등록합니다. Mac의 응용 프로그램 폴더와 Windows의 설치 프로그램 목록에서도 이름과 설치 버전을 읽습니다. 공지 출처가 미연결된 앱은 선택 목록의 링크 버튼으로 연결할 수 있고, 다른 위치에 설치했다면 **설치 폴더 선택**을 사용합니다.
- **npm 프로젝트 선택**에서 `package.json`과 `node_modules`가 있는 프로젝트의 폴더를 선택합니다. 직접 선언한 의존성 중 실제로 설치된 패키지의 버전을 읽어 선택 목록에 추가합니다. 고른 패키지와 버전은 OSV와 연결됩니다.
- **항목 등록**에서 이름을 입력하면 빠른 선택이 바로 필터링되고, 잠시 후 NVD와 npm 검색 결과가 표시됩니다. 예를 들어 `nestjs`를 검색한 뒤 `@nestjs/core`를 고르면, 입력한 설치 버전의 공지를 OSV에서 확인합니다. 각 출처의 **결과 더 보기**로 추가 항목을 확인할 수 있습니다.
- **직접 등록**에서 다른 제품 이름, 분류, 버전을 추가할 수 있습니다. **제품·패키지 검색 및 연결**에서 항목을 선택하면 해당 식별자로 공지를 확인합니다.
- 검색 결과에 제품이 없으면 **공지 출처 미연결** 상태로 저장하고 나중에 **항목 수정**에서 연결할 수 있습니다.
- 앱을 실행하면 최근 확인 시점에 따라 조회하고, 실행 중에는 두 시간마다 다시 확인합니다. **보안 공지 확인** 버튼으로도 조회할 수 있습니다.
- **데스크톱 알림**에서 알림을 켜면 같은 등록 버전의 공지를 중복 알림하지 않습니다. **테스트 알림**으로 확인할 수 있습니다.
- 조회 결과와 등록 목록은 이 기기에 저장합니다. 검색어를 NVD와 공개 npm 레지스트리에 보내며, 공지 조회 시 연결된 제품이나 패키지 식별자와 버전을 NVD 또는 OSV에 보냅니다. 세부 적용 조건과 수정 버전은 공지 원문에서 확인할 수 있습니다.

## 개발자 후원

GitHub 저장소의 Actions 변수 `PATCHBELL_SUPPORT_URL`에 운영자의 공개 Buy Me a Coffee 페이지 URL을 넣으면, 새 앱 빌드와 홈페이지 배포에 후원 버튼이 표시됩니다. 로컬 앱에서는 `--dart-define=PATCHBELL_SUPPORT_URL=...`로 같은 주소를 넘길 수 있습니다.

## 배포

**Release Patchbell desktop** 워크플로는 Windows ZIP과 macOS DMG를 GitHub Releases에 올립니다. 홈페이지를 배포할 때는 **Deploy Patchbell homepage** 워크플로를 따로 실행합니다. 이때 최신 공개 릴리스의 설치 파일을 다운로드 버튼에 연결합니다.
